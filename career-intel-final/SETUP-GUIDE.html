GitHub is where your code lives. Both Railway and Vercel will pull from it automatically — so you only ever edit code in one place.
1
Create a GitHub account (if you don't have one)
Go to github.com/signup — it's free.
2
Create a new repository
1. Click the + icon in the top-right corner of GitHub
2. Click New repository
3. Name it career-intel
4. Set it to Public
5. Click Create repository
3
Install Git on your computer
Download from git-scm.com/downloads and install.
On Mac it may already be installed. Check by opening Terminal and typing git --version.
4
Install Node.js
Download the LTS version from nodejs.org and install.
5
Open Terminal and navigate to your project folder
On Mac: open Terminal app. On Windows: open Command Prompt.
Navigate to where you extracted the career-intel-final folder: 
cd Downloads/career-intel-final
Tip: type cd then drag the folder into Terminal — it fills in the path automatically.
6
Push your code to GitHub
Run these commands one by one (replace YOUR-USERNAME with your GitHub username):
git init
git add .
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/career-intel.git
git push -u origin main
It will ask for your GitHub username and password. For password, use a Personal Access Token (GitHub no longer accepts regular passwords).
7
Verify it worked
Go to github.com → your profile → you should see career-intel with all your files inside.
✅ Code is on GitHub! Click 🚂 Railway above to deploy the backend.
Railway runs the backend — the part that calls Claude AI to search for opportunities. Free tier gives $5/month credit which is more than enough.
1
Get your Anthropic API key
1. Go to console.anthropic.com
2. Sign up (free) and add a payment method (you won't be charged immediately)
3. Click API Keys → Create Key
4. Copy the key — it starts with sk-ant-api03-...
5. Save it somewhere safe — you only see it once
2
Create a Railway account
Go to railway.app → click Login → Login with GitHub.
3
Create a new project from your GitHub repo
1. Click New Project
2. Click Deploy from GitHub repo
3. Select career-intel from the list
4. Railway will start building automatically
4
Add your Anthropic API key as an environment variable
1. Click on your service (the box that appeared)
2. Click the Variables tab
3. Click + New Variable
4. Name: ANTHROPIC_API_KEY · Value: your key from Step 1
5. Press Enter — Railway will redeploy automatically 
ANTHROPIC_API_KEY = sk-ant-api03-your-actual-key-here
5
Generate a public domain for your backend
1. Click Settings tab on your service
2. Scroll to Networking → click Generate Domain
3. You'll get a URL like: career-intel-production.up.railway.app
Copy this URL — you need it in the next step!
6
Test your backend is working
Open your browser and go to your Railway URL + /api/health:
https://career-intel-production.up.railway.app/api/health
You should see: {"{"}"status":"ok","time":"2026-..."{"}"}
If you see that — your backend is live!
✅ Backend is running! Click ▲ Vercel above to deploy the frontend.
Vercel hosts the website (the React frontend). It's free for personal projects and deploys in seconds from GitHub.
⚠️ Before this step, you need your Railway URL from Step 2. It looks like: career-intel-production.up.railway.app
1
Update vercel.json with your Railway URL
Open the file vercel.json in your project folder. Find this line:
"destination": "https://YOUR-APP.railway.app/api/:path*"
Replace YOUR-APP with your actual Railway subdomain. Example:
"destination": "https://career-intel-production.up.railway.app/api/:path*"
Save the file, then push it to GitHub:
git add vercel.json
git commit -m "add railway url"
git push
2
Create a Vercel account
Go to vercel.com → click Sign Up → Continue with GitHub.
3
Import your project
1. Click Add New… → Project
2. Find career-intel in the list → click Import
3. Vercel auto-detects Vite — leave all settings as defaults
4. Click Deploy
4
Wait ~60 seconds for it to build
You'll see a progress bar. When it finishes, Vercel shows a "Congratulations" screen with your URL.
5
Open your live app!
Your URL looks like: career-intel-xyz.vercel.app
Click it → you should see Career Intel load.

1. Go to Documents → upload your resume PDF and certifications PDF
2. Wait for Claude to parse your profile
3. Go to Opportunities → click Refresh
4. Live results in ~30 seconds 🎉
6
Bookmark your URL
Add it to your browser bookmarks. Visit anytime to refresh opportunities.
Every time you push new code with git push, both Railway and Vercel redeploy automatically.
🎉 You're live!
💰 Cost: Railway ~$0–1/month · Vercel free · Anthropic ~$0.04 per Refresh
🔄 Future updates: edit code → git push → auto-redeploys in 60 seconds
📱 Works on phone too — just open your Vercel URL in mobile browser
